# MegaVGMPlayer v2.6 RC9 corresponding source

Component commits and binary identities are in `Provenance/RC9/integration.json`. The package uses independent source histories for Host, SID Preparer, Setup and Remote.

- **Engine A–G RBFs** use the byte-identical RC8 images and the corresponding per-engine `Engines/*/SourceBuild.zip` inputs. Start at the root QPF of each archive. See `Provenance/RC7-IDENTITY.json` for unchanged components. Intel I02 has unresolved license scope. The two inherited PLL inputs retain their headers.
- **Host and Supervisor** use the `Host/tools` source with `Provenance/host-flags.sh` and `Provenance/build-host.sh`. Set `SID_AUDIT_ROOT` to the absolute path of `Host`, use a fresh absolute output directory and use the Arm GCC 10.2-2020.11 build. The updated Supervisor corresponds to the RC9 Host commit. Unchanged Controller and ctl retain the RC8 binaries and producing Host commit.
- **Main** uses its recorded commit, Makefile and Arm GCC 10.2-2020.11. `relink-main.sh` accepts an ARM sysroot with ABI-compatible linker inputs. The package retains the dedicated Main and resolves BlueZ from MiSTer Linux.
- **Remote and PWA** use `Remote`. Use Go 1.21.9, `GOOS=linux GOARCH=arm GOARM=7 CGO_ENABLED=0`, `-trimpath -buildvcs=false` and linker flags `-s -w -X main.fullRoot=/media/fat/MegaVGMPlayerFull`. Pinned built assets are in `cmd/megavgm_remote/web/build`; frontend source and lockfile are in `frontend`. NSF preparation is in the same source tree.
- **Setup, Recovery and Uninstall** use the separate, already expanded `Setup` source, including the v2.5 cache migration. Build `./cmd/megavgm_full_setup` from that directory using the same Go target settings and `-ldflags '-s -w'`. The required gorilla/mux source archive is under `Dependencies`.
- **SID Preparer** uses `SID`, the pinned libsidplayfp archive and write-observer patch. Set `MEGAVGM_LIBSIDPLAYFP_ARCHIVE` to the included archive and use the Arm GCC 10.2 toolchain with `build_arm.sh` and a fresh output directory. Build from the recorded SID commit for the exact provenance stamp. The archive includes build/test code and the duration policy.
- **ARM runtime** uses the pinned Arm GNU-A 10.2-2020.11 release. [Exact glibc source and configuration](https://github.com/dai-VGM/MegaVGMDrive/tree/07174e18f6832b2436e4b385642e0c309297a74d/source-dependencies/GNU). The GCC source archive `gcc-arm-src-snapshot-10.2-2020.11.tar.xz` is retained separately, SHA256 `41e65e665fbd6e73cbadb046d9d2f324987db65e7ac4753f4dea827928bde444`.
- **Python** is CPython 3.9.6. Configuration is in `Provenance/CPython-Buildroot-config.txt`. [CPython 3.9.6 source](https://github.com/python/cpython/tree/db3ff76da19004f266b62e98a81bdfd322861436).
